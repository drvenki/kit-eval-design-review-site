Nominal total 7 arms × 3 × 3 = 189 analysed libraries. The prep sheet holds 207 rows, the extra 18 being the EVO cfDNA re-prep (9) and the IL cfDNA re-hybridisation (9).

Nesting

replicate ⊂ batch ⊂ (kit × sample type). Batch is nested in kit, not crossed with it: "B1" for KAPA15 and "B1" for WM are unrelated events. The design therefore carries no information with which to separate a kit effect from a day effect, except where two kits happened to be prepped on the same day.

DNA sources: one pool per matrix, no biological replication

  • cfDNA — one pool of leftover plasma from several ProBio participants.
  • gDNA — one pool from two blood donors (9610 ng total, NucleoSpin Blood Mini).
  • FFPE — one pool of punches from nine anonymous blocks, 1–4 years old, extracted separately and then mixed (QIAgen AllPrep FFPE DNA/RNA, 80 °C substitution).

All replication is technical. This is legitimate for a chemistry benchmark, but it has to be stated: the study estimates kit performance on one DNA preparation per matrix type, and the confidence intervals do not cover donor-to-donor or block-to-block variability.

Downstream steps, which are well controlled

Say this in the Methods, it is a strength

  • Single target-capture date for the main run (dev250429-* hybridisation pools), Twist Target Enrichment Standard hybridisation v1, and capture performed by one operator (VK) for every library.
  • Sequencing is not confounded with kit. NovaSeq X, flow cells 22YVW7LT3 (748 lane-records), 232Y53LT3 (126), 232MLFLT3 (64), lanes 1–8. Libraries were pooled and spread across lanes.
  • One bioinformatic pipeline, one reference, one subsampling depth (35 M read pairs) for every library.

Hybridisation pools

Capture pool is aliased with preparation batch for most kits, one pool per batch (EVO FFPE/gDNA → E3 / F3 / G3; WM FFPE/gDNA → B3 / C3 / D3; KAPA15 FFPE → F1 / A2 / D2). For modelling this is harmless: the batch random effect absorbs prep day and capture pool together as one nuisance level. It does mean you cannot attribute a batch effect to one or the other, which is worth one sentence in the Methods. One record (KAPAON-COV gDNA B3) has #N/A for the pool.
